# Kai Williams Portfolio

This repository contains the source code for my portfolio website, based on my resume. It highlights my experience in information technology, cybersecurity, data research, and technology support.

[View the live website](https://kai-williams-portfolio.kaiwilliams0000.chatgpt.site)

The website is built as a self-contained [index.html](index.html) file and includes a downloadable copy of [my résumé](Kai-Williams-Resume.docx). Open `index.html` in a browser to view the portfolio locally.

## Power BI projects

- [Internal Audit Dashboard](Internal-Audit-Dashboard.pbix) — completed project presented with a limited public summary.
- [Center for Sport Dashboard](Center-for-Sport-Dashboard.pbix) — collaborative project; this work includes contributions from other team members and project partners.

The `.pbix` files require Power BI Desktop to open.
